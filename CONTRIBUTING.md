# Contributing / Contribuir

## English

Contributions are welcome, but this repository has a **single maintainer** and **every external
contribution must be approved by the maintainer before it is merged**.

- **Pull requests only.** `main` is a protected branch: direct pushes are not allowed and any pull
  request needs the maintainer's review (**1 approval**) before it can be merged.
- **Opening a PR does not mean it will be merged.** The maintainer decides; a PR may be closed
  without merging and without further explanation.
- **Small, focused PRs.** Say what you change and, above all, how you tested it (device, Android
  version, exact steps, evidence). "It works for me" is not a test.
- **No authorship claims.** Authorship of this project belongs to its maintainer. Do not add your
  name to the repository description, README or website as if you were a contributor unless your
  changes have actually been merged. Forks are copies: they grant no authorship over the original.

Commit messages use a type prefix: `feat:`, `fix:`, `style:`, `refactor:`, `test:`, `docs:`,
`chore:` — for example `fix: Fix crash during launch on certain phones`.

## Español

Las contribuciones son bienvenidas, pero este repositorio tiene **un único mantenedor** y **toda
contribución externa tiene que ser aprobada por el mantenedor antes de fusionarse**.

- **Solo por pull request.** `main` es una rama protegida: no se permite empujar directamente y
  cualquier pull request necesita la revisión del mantenedor (**1 aprobación**) antes de poder
  fusionarse.
- **Abrir un PR no significa que se vaya a fusionar.** Decide el mantenedor; un PR puede cerrarse
  sin fusionarlo y sin más explicación.
- **PR pequeños y concretos.** Di qué cambias y, sobre todo, cómo lo has probado (dispositivo,
  versión de Android, pasos exactos, evidencia). "A mí me funciona" no es una prueba.
- **Nada de atribuirse la autoría.** La autoría de este proyecto es de su mantenedor. No añadas tu
  nombre a la descripción del repositorio, al README ni a la web como si fueras colaborador si tus
  cambios no se han fusionado. Un fork es una copia: no da autoría sobre el original.
