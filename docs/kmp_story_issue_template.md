## Ready-to-Copy Example

### Summary

- Story ID: KMP-202
- Epic: EPIC-KMP-02
- Priority: p0
- Estimate: 3 points

### Problem

Android packaging is not wired to the new KMP orchestrator, so generated KMP projects cannot produce a debug APK reliably.

### Scope

- In scope: KMP orchestrator wiring for Android packaging, artifact reporting, smoke test update.
- Out of scope: Desktop packaging, Wasm/iOS targets.

### Implementation Tasks

- [ ] Wire Android packaging stage in orchestrator.
- [ ] Persist Android artifact metadata in build report.
- [ ] Add smoke test for KMP scaffold Android package path.

### Deliverables

- Android packaging path callable from KMP build manager.
- Build report contains APK output path and duration.

### Definition of Done

- [ ] Generated KMP sample builds debug APK successfully.
- [ ] Build report includes Android status, duration, and artifact path.
- [ ] Smoke test passes in CI.

### Acceptance Tests

- [ ] Unit tests added/updated.
- [ ] Integration or smoke test added/updated.
- [ ] Manual verification steps documented.

### Telemetry and Diagnostics

- Metrics/events to emit: android_package_start, android_package_end.
- Error categories to map: packaging_error, dex_error, manifest_error.
- Logs that must be visible in diagnostics: stage start/end and artifact output path.

### Feature Flag and Rollout

- Feature flag name: KMP_EXPERIMENTAL_ENABLE
- Default state: OFF
- Rollback strategy: disable flag and route to existing Android-only build flow.

### Dependencies

- Blocked by: KMP-201
- Blocks: KMP-206

### Risks and Mitigations

- Risk 1: Packaging path may fail on low-memory hosts.
- Mitigation 1: Add memory guard and fail-fast diagnostics.

### Verification Notes

Attach build logs, APK path, and test evidence.
